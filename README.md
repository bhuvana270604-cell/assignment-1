Global Seismic Trends: Data-Driven Earthquake Insights

Project Description

Global Seismic Trends: Data-Driven Earthquake Insights is a data analysis project that focuses on understanding global earthquake activity using historical earthquake data. The project analyzes important earthquake attributes such as location, magnitude, depth, date, country, and region to identify meaningful seismic patterns and trends.

The project involves collecting and preprocessing earthquake data, handling missing and duplicate values, converting date information, categorizing earthquakes based on their depth, and performing exploratory data analysis using Python.

A key objective of this project is to identify countries that experienced both shallow and deep earthquakes within the same month. The project also determines the three most seismically active regions by combining earthquake frequency with average earthquake magnitude.

Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn are used for data cleaning, analysis, visualization, and scoring. Various visualizations are created to understand earthquake frequency, magnitude distribution, depth distribution, and regional seismic activity.

The final analysis provides data-driven insights into global earthquake patterns and demonstrates how data analytics techniques can be used to identify significant seismic trends and support earthquake-related research.
